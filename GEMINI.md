# Betting Tips AI

This extension connects Gemini CLI to the remote Betting Tips AI MCP server at https://bettingtipsai.com/api/mcp over Streamable HTTP.

A free bettingtipsai.com account and OAuth sign-in are required. Unauthenticated requests return HTTP 401. When the CLI prompts you, sign in in the browser and approve the `tips:read` scope.

Content is for users aged 18 or over. Predictions are informational only. They are not guarantees, financial advice, or an instruction to place a bet. Gambling can be addictive. Please play responsibly.
